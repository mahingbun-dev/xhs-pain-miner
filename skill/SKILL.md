# 🔍 XHS Pain Miner — 从痛点到机会

## 能力

给定一个品类关键词，回答一个独立开发者最关心的问题：**这个方向值不值得做？**

- **痛点聚类**：把散落在笔记与评论中的抱怨归并成痛点簇，提及次数由簇大小算出（可复现、可核对）
- **竞品调研**：自动查 GitHub 与 App Store（iTunes Search API），判断"这个方向是不是已经被人做掉了"
- **机会评分**：多因子加权（痛点强度 / 提及量 / 趋势 / 竞品空白度 / 实现难度），可解释、权重可调
- **证据链**：每条结论都能点回原文引用

## 使用方式

先确认环境（不发起网络请求）：

```bash
xhs-pain-miner doctor
```

**先做一次采样式验证**（不需要 API Key、不联网、不触碰平台）：

```bash
xhs-pain-miner collect -k "<品类关键词>" --backend fixture
```

**完整分析**：

```bash
xhs-pain-miner mine -k "<品类关键词>" -n 200
```

需要图片分析时加 `--deep`（成本与耗时显著上升，建议先用 `MAX_VLM_CALLS` 设上限）。

## 前置条件

用户需要自行提供**合法的数据来源**与**自己的 API Key**：

- 采集：默认使用内置样例数据。真实采集需要在本地配置采集器后端，见
  [docs/collector-plugin.md](../docs/collector-plugin.md)。
  **本工具不附带任何平台采集实现，也不会替用户采集数据。**
- 模型：在 `.env` 中配置 `LLM_API_KEY`（默认 DeepSeek）。

## 合规约束

请勿用本工具做以下事情，也不要向用户建议这些做法：

- 绕过平台风控（签名逆向、IP 池、账号池）
- 把采集到的原文或个人数据上传、转售、或做成公开数据服务
- 采集直播、私信等非公开内容

判例依据见 [docs/competitive-analysis.md](../docs/competitive-analysis.md#三合规与判例)。
