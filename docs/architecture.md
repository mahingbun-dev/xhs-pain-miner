# 🏗️ 架构设计

## 系统架构

```
用户输入 (关键词)
       │
       ▼
┌──────────────┐
│  数据采集层   │  MediaCrawler / MCP
│  Crawler     │  采集笔记 + 评论 + 图片
└──────┬───────┘
       │
       ▼
┌──────────────┐
│  分析引擎层   │
│  ├─ NLP      │  情感分析 / 关键词 / 聚类
│  ├─ VLM      │  图片内容理解
│  └─ Miner    │  痛点提炼算法
└──────┬───────┘
       │
       ▼
┌──────────────┐
│  输出层       │
│  ├─ Web      │  交互式仪表盘
│  ├─ Report   │  PDF / HTML / JSON
│  └─ Skill    │  Codex / Claude Code
└──────────────┘
```

## 数据流

1. **采集**: 用户输入关键词 → 爬取小红书笔记/评论/图片
2. **清洗**: 去重、过滤、格式化
3. **分析**: NLP 文本分析 + VLM 图片分析
4. **挖掘**: 从分析结果中提炼结构化痛点
5. **聚合**: 频率统计、情感评分、趋势计算
6. **输出**: 可视化报告、导出文件、Skill 输出
