# ❓ 常见问题

## Q: 需要什么 API Key？

A: 需要 OpenAI API Key（用于 GPT-4o 多模态分析）。设置环境变量 `OPENAI_API_KEY` 或在 `.env` 文件中配置。

## Q: 采集笔记会被封号吗？

A: 工具内置了频率控制和随机延迟。建议使用代理和多个 Cookie 轮换，降低风险。

## Q: 分析一个品类大概需要多久？

A: 取决于笔记数量。200 篇笔记大约需要 3-5 分钟（含评论分析）。

## Q: 支持哪些平台？

A: Phase 1 专注小红书。Phase 2 将扩展到抖音、知乎等平台。

## Q: 可以商用吗？

A: MIT 协议，自由商用。如有增值功能需求，请关注后续版本。
